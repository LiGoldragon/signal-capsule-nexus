# signal-capsule-nexus

Fresh version 1 generated signal contract repository for capsule-nexus.
Its Subscribe is answered by a stream: `Subscribed.Stream<Panes Known>`, the session's panes that are not Dead, then each pane that moved, whole. `Panes` bears `signal::Following`, the fold a subscriber and the Nexus both apply: the Known given replaces the pane, or is taken in, and a Known whose state is Dead takes the pane out.
